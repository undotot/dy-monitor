# 监控室 UI/UX 重设计 v2.1 · 墙 + 检查器

> 依据：v1.4.6 当前 `src/` 实现（2026-10-17）。
> 实现状态：主体布局与交互已落地，主题色切换为斗鱼黑暗模式（中性黑灰底 + 品牌橙 `#ff5d23`，选中为品牌橙细描边）。更新提示浮层、页面内专注视图等次要项仍保留现状。
> 交付：本文档负责现状审计与交互规则；配套设计图见
> [ui-ux-design-board.html](ui-ux-design-board.html)（PC / iPad 横竖屏、触控面板与状态规范）。
> 本文只做设计，不修改生产代码。落地映射见 §8。

---

## 1. 结论摘要

1. **画墙继续做主角，但把“操作这一路”从画格里拿出来。** 当前每个画格自带悬浮工具条、更多菜单、右键菜单和画格内弹幕设置，四套入口重叠；小窗缩到 85px 时按钮只剩十几像素。新方案改为“选中一路 → 固定检查器 / 底部控制条 → 同一个更多面板”，画格里只留身份、状态和少量就地反馈。
2. **PC 用停靠检查器，iPad 用底部控制条 + 底部面板。** 同一套命令、同一套状态，只换呈现位置。PC 不新增常驻底栏，避免占掉视频高度；iPad 不再让 344px 抽屉吃掉近半屏宽。
3. **所有核心操作都有可见入口。** 悬停、右键、长按、拖动只作为快捷方式，不再是唯一路径。放大、换位、音量、弹幕设置、移除都必须能点得到。
4. **触屏按 44/48px 设计，不再随视频缩小。** 小窗只减少入口，不缩小命中区；输入框在触屏上 16px 起，避免 iPad Safari 聚焦自动放大。
5. **只保留“同一套命令”这一条原则。** 状态语义、选中语义、声音对象、面板作用范围全部拆开；选中一路不改变声音，独奏不隐式改选中，移除可撤销。

## 3. 设计原则

1. **一层命令。** 所有房间命令只有一个清单和一个执行层；PC 检查器、iPad 底部控制条、更多面板只是同一清单的不同呈现。
2. **选择很轻，动作很明确。** 轻点/单击只选中，不改变布局、声音或播放；动作必须由显式按钮触发。
3. **画面优先。** 画格内不加常驻工具条；面板在触屏上是覆盖式，只有宽屏才停靠。
4. **每种状态只用一个视觉通道。** 身份=名字，直播=状态点，选中=品牌橙细描边（不做大面积填充），主画面=“主”徽标，声音=喇叭/独奏标，异常=红点+文字。
5. **没有悬停也能完成全部操作。** 悬停/右键/长按/拖动是加速器，不是入口。
6. **能力诚实。** 不支持的 PiP/全屏/逐路音量不装成可用；给出替代路径。

## 4. 新信息架构

### 4.1 PC（≥1101px 容器宽）

```text
┌ 顶栏 56 ─────────────────────────────────────────────────────────────┐
│ 斗 监控室 v1.4.6  9/16 格 · 5 路播放 · 1 路异常  [面板] [布局3列] [声音] [+添加] [⋯] │
├──────────────────────────────────────────────┬───────────────────────┤
│ 画墙（自动平铺 / 主次放大）                     │ 检查器 320            │
│                                              │ 当前房间 | 房间库      │
│  09:16 深夜电台 ...                           │ 深夜电台  ● 直播中     │
│                                              │ 暂停 静音 独奏 放大    │
│                                              │ 音量 72% ────────     │
│                                              │ 弹幕 开 · 跟随全局     │
│                                              │ 画质 蓝光 8M          │
│                                              │ 重新取流 / 替换 / 打开  │
│                                              │ 移除房间              │
└──────────────────────────────────────────────┴───────────────────────┘
```

- 顶栏只保留：品牌/版本、房间计数与健康、面板、布局、声音、添加房间、更多。
- 主增益、声音模式、全部播放/停止、设置、退出监看进入“声音”浮层和“更多”菜单。
- 检查器默认停靠（宽 320px），可用顶栏/检查器标题栏的折叠按钮收起；收起后画墙重算。
- 未选中房间时检查器显示“房间库”：已添加房间列表、添加按钮、墙统计，避免空白面板。
- 检查器只服务“当前房间”，不塞入全局设置；设置是独立弹层。

### 4.2 iPad 横屏 / 窄桌面（761–1100px 容器宽）

```text
┌ 顶栏 58 ─────────────────────────────────────────────┐
│ 斗 监控室  6/16 · 5 路播放       [布局] [声音] [+ 添加] [⋯] │
├──────────────────────────────────────────────────────┤
│ 画墙 3×2 / 2×3                                        │
│                                                      │
├ 底部控制条 76 + safe-area ─────────────────────────────┤
│ 深夜电台   ● 直播中 · 1080P   [暂停][静音][独奏][放大][弹幕][更多] │
└──────────────────────────────────────────────────────┘
```

- 不设常驻侧栏；检查器内容改为底部控制条（选中态）+ 底部面板（更多/房间库/设置）。
- 底部控制条始终显示当前选中房间名和状态；无选中时显示“轻点画面选择房间”+添加房间。
- 六个 48px 动作常驻，更多面板承载画质、重取、弹幕设置、替换、全屏/PiP、移除。

### 4.3 iPad 竖屏 / 分屏（<760px，或竖屏时房间面板单列）

- 顶栏压缩为：logo + 计数 + 添加 + 更多；品牌文字可隐藏。
- 画墙使用 2 列；底部控制条保留；≤640px 时隐藏独奏，动作减为 5 个（暂停、静音、放大、弹幕、更多），独奏进入更多。
- 添加/房间库/设置/动作面板全部使用全宽底部面板，最大高度 `min(88dvh, 100% - 24px)`。

### 4.4 断点与输入密度分离

| 条件 | 排版 | 密度 |
|---|---|---|
| 容器 ≥1101px | PC 停靠检查器 + 右侧设置面板 | 鼠标：36–40px；触控：44–48px |
| 641–1100px | iPad 横屏/窄桌面：顶部窄栏 + 底部控制条 + 面板 | 44–48px（凡粗指针） |
| ≤640px | 竖屏/分屏：紧凑顶栏、五动作控制条、全宽面板 | 44–48px |
| `any-pointer: coarse` | 不改变排版 | 命中区 44px 起，核心 48px |
| `hover: hover and pointer: fine` | 允许悬停快捷按钮 | 可降到 32–36px |

容器宽度由 `ResizeObserver` 写到 `data-width="wide|medium|narrow"`，不依赖 User-Agent；输入能力由 `any-pointer`/`pointer` 和 `pointerdown` 的 `pointerType` 决定。iPad 接妙控键盘/触控板时，排版不变，悬停快捷方式可启用。

## 5. 组件与交互规则

### 5.1 画格

**默认态**

- 左上：状态点 + 主播名（11.5/12px，玻璃胶囊，最大宽度随画格收缩），必要时加“主”徽标。
- 右上：仅静音时显示静音图标；非静音不显示常驻喇叭。
- 左下：只在非正常态显示一句话：`排队中 · 前面 2 路`、`未开播 · 每分钟检查`、`重连 2/5`、`播放异常` + [重试]。
- 不显示工具条、不显示更多按钮、不显示画格内弹幕设置入口。

**选中态**

- 2px 斗鱼橙（`#FF7A45`）内描边 + 名字胶囊橙描边；不改变画格尺寸、间距或视频比例。
- 桌面：选中画格右下角出现 3 个 32px 快捷按钮（播放/暂停、放大、更多）；悬停未选中画格只出现同样 3 个，不改变选中。
- 触屏：选中画格右下角出现 1 个 44px “⋯”；底部控制条同时变为该房间。点空白处取消选中。

**主画面态**（主次布局）

- 名字胶囊内显示“主”徽标；检查器/控制条显示“放大中”，并提供“恢复平铺”。
- 放大由显式按钮触发；双击（PC）只是快捷方式。

**异常态**

- 红点 + 红色文字 + 就地“重试”；不只用颜色。
- 正在重连显示“重连 2/5 · 4 秒后”，点击立即重试。

**加载/排队**

- spinner + 阶段文案；排队显示位置，不显示无法操作的按钮。
- 全局额度满时，顶栏计数变为 `额度 8/8`，检查器提示“排队中，前面 N 路”。

### 5.2 检查器（PC）

分两个页签：

1. **当前房间**：选中后显示。
   - 身份：头像/首字、主播名、分类、房号、状态、清晰度、延迟。
   - 四个主操作：暂停/继续、静音、独奏、放大/恢复（48px 高，图标+文字）。
   - 声音：音量滑杆（触控 44px 命中带）、±5% 按钮、静音状态、是否跟随主增益。
   - 弹幕：开关 + “跟随全局 · 半屏 · 简单”摘要 + “设置”（打开单房弹幕面板）。
   - 画质：下拉/弹层；重新取流；替换房号；打开直播间。
   - 底部：移除房间（红色，带撤销）。
2. **房间库**：搜索、来源页签、房间列表、添加按钮；与添加面板共用组件，只是宽 320px 的侧栏形态。

无选中时默认显示“房间库”；选中后切到“当前房间”，用户手动切回房间库则保留到下次选中。

### 5.3 底部控制条（iPad）

- 左侧：房间名（截断）+ 状态（`直播中 · 1080P` 或 `排队中`）。
- 右侧：暂停/继续、静音、独奏、放大、弹幕、更多，六个 48px 按钮；每个都有可见文字（10px）。
- 始终位于安全区域之上；不自动隐藏。
- 无选中：显示“轻点画面选择房间”+“添加房间”按钮；这是触屏的默认引导。
- 更多面板从底部滑出，含拖拽把手、分组标题和 48–52px 行高。

### 5.4 更多面板（一套动作清单）

分组顺序固定，低频/破坏性动作在底部：

```text
播放      暂停/继续 · 重新取流
声音      静音 · 独奏 · 音量（打开大滑杆 + ±5%）· 跟随主增益
画面      放大/恢复 · 画质 · 全屏（能力可用时）· 画中画（能力可用时）
弹幕      开关 · 弹幕设置
房间      替换房号 · 打开直播间
────────────────────────
移除房间（红色，单击后 Toast 可撤销 6 秒）
```

- 桌面右键菜单改为同一张清单，锚定光标；不再维护第二份文案。
- 触屏长按画格 = 打开同一面板；长按不是唯一入口，选中画格的“⋯”永远可点。
- 画格内旧“更多”菜单、旧右键菜单、旧工具条代理全部删除。

### 5.5 添加房间

- PC：从顶栏“添加房间”打开右侧 440px 添加抽屉；检查器“房间库”页签也可查看已添加房间并打开添加。
- iPad：全宽底部面板，高度 88%，顶部搜索固定，列表滚动，底部选择托盘固定。
- 结构：
  1. 标题 + 关闭（44/48px）。
  2. 搜索框 48px，16px 字号；显式搜索按钮/清空；停输 500ms 仍自动搜索；IME 组词期间不请求；Enter 在非组词时搜索。
  3. 来源 chips：`关注 12`、`历史`、`团播`、`手动`；不再把团播做成平级大页签+横向卡片轨道，团播在来源里选。
  4. 列表行 56–68px：整行可点选，圆形勾选 26px，头像 40px，名字/分类，右侧状态徽章（直播中/轮播/未开播/已在墙/检查中）。
  5. 已添加/当前房间的行禁用并写“已在墙”，但仍显示在结果里，避免搜索“消失”。
  6. 底部固定：`已选 N 个`、`清空`、`加入墙 N 个`（主按钮）；跨页/跨搜索保留选择。
  7. 添加结果用“部分成功”文案，失败保留勾选；成功后可留在面板继续添加，或关闭返回墙。
- 手动页：大文本域每行一个房号/链接；按钮“解析并添加”；替换模式只允许一个目标。
- 空结果/失败/加载都有文案和重试；不出现空白列表。
- 新房间画质从搜索头部移到“添加选项”折叠行或底部托盘，避免和搜索抢位置。

### 5.6 设置

- PC：右侧 392px 覆盖式设置面板（不挤压画墙），顶部页签（播放 / 弹幕 / 声音 / 工作区 / 诊断），内容滚动；关闭后焦点回到“更多”。
- iPad / 窄屏：全宽底部面板，顶部横向页签 + 内容滚动；输入 16px，开关行 48px。
- 分组：
  - **播放**：并发额度、请求 H.265、暂停页面主视频、打开监控室时（每次询问/自动加载/直接面板）。
  - **声音与提醒**：新房间静音、独奏跟随焦点、开播提醒、提醒声音、开播自动取流。
  - **弹幕默认**：全局开关、显示方式、飘屏范围、版式；明确“只影响默认值，单房可覆盖”。
  - **工作区**：预设保存/载入/删除、清空历史。
  - **诊断**：日志折叠，复制/清空；默认不展开。
- 版本/更新说明从顶栏移到“关于”或更多菜单，减少常驻噪声。
- 主题枚举如果没有真实样式，删除或补齐；不要让用户看到无效选项。

### 5.7 弹幕

- **作用域**：
  - 全局默认在设置里；单房设置从检查器/更多面板进入，标题写“该直播间 · 弹幕设置”。
  - 单房面板顶部显示“跟随全局”与当前摘要；改动任一字段变为“已自定义”，提供“恢复跟随全局”。
- **显示方式**：
  - 飘屏在画格内。
  - 弹幕栏不再挤出画格内部宽度。当前实现把它改为画格右侧覆盖层，可随时关闭；横屏房间面板和检查器仍显示弹幕设置入口。
  - iPad 竖屏不提供画格内弹幕栏，避免视频过窄。
- **入口收敛**：保留画格内开关（控制条/检查器）和“弹幕设置”一个齿轮；删除第三、第四个齿轮重复入口。
- 弹幕设置控件命中区 44px；`1/4 屏/半屏/3/4 屏/全屏` 仍用分段，但加文字说明。

### 5.8 声音

- 全局三态：混音 / 独奏 / 静音；主增益在声音浮层，不放顶栏常驻。
- **独奏对象独立于选中对象**：
  - 选中 B 不改变正在独奏的 A；独奏按钮明确作用于当前房间并显示“正在独奏 A”。
  - 如果开启“独奏跟随焦点”，独奏对象随主画面/选中变化；否则保持不变。
  - 移除独奏对象时切到全部静音并提示，避免其他房间突然出声。
- 单房间音量用滑杆 + ±5%（触屏可点）；静音一次点击生效，不再“第一次展开、第二次静音”。
- iPad 能力：如果 `video.volume` 在该环境不生效，隐藏无效百分比，显示“使用系统音量”说明；保留静音/独奏。若后续接 Web Audio 增益，再恢复逐路音量。

### 5.9 换位

- 桌面：
  - 保留专用拖拽手柄（名字胶囊或“整理位置”模式中的手柄），不再整格可拖。
  - 顶栏“更多 → 整理位置”进入模式：画格显示序号，源格斗鱼橙描边，目标格虚线；点两个画格交换；顶部条“取消 / 完成”。
- iPad：
  - 全部通过“整理位置”模式完成：点源 → 点目标 → 交换；不依赖拖动。
  - 拖动只作为可选加速；长按拖拽需要 `pointer` 事件与 `touch-action` 配合，不作为唯一路径。
- 交换后保持播放器实例、音量、弹幕设置与主画面身份；取消不改顺序。

### 5.10 移除、退出与恢复

- 移除：动作面板中的红色项，单击后 Toast `已移除“深夜电台” · 撤销`，6 秒内可恢复房间配置并重新取流（不承诺恢复已释放的连接）。
- 退出监看：更多菜单 → 确认弹层（不是顶部 Toast），写明“停止全部播放、返回我的关注、布局已保存”；主按钮“退出监看”，次按钮“继续观看”。
- 打开时：恢复询问改为包含房间头像/数量的摘要；`加载上次直播间` 主按钮，`暂不加载` 次按钮；“记住选择”折叠在下方。选择“暂不加载”后进入空墙引导，而不是直接打开设置抽屉。
- 空墙：`添加房间` 主按钮 + `加载上次 N 个房间`（有 pending 时）+ 一句操作提示；不再显示孤零零的“监控室是空的”。

### 5.11 布局

- 名称改为 `自动 / 1 列 / 2 列 / 3 列 / 4 列`，并在浮层里说明“列数，行数自动”。
- “放大”是主次布局，不是单画面全屏；检查器/控制条用“放大/恢复平铺”。
- 主次布局继续使用现有综合均衡算法；指定房间就是主窗。副窗源比例混合时保留所选主窗，比例不同的小窗以黑边适配并在画墙右上角提示，不再自动换到其他直播间。
- 单画面观看走画格全屏（能力可用时）或页面内专注视图；iPad 全屏失败时回退到“专注视图”（单格铺满画墙 + 返回按钮），不要只报错。

### 5.12 更新提示

- 版本徽标点击/轻点打开说明浮层（PC 悬停也可），浮层内是“查看更新 / 打开安装页”，不再单击直接跳下载。
- 触屏上浮层用底部面板或居中卡片，44px 按钮。

## 6. 双端交互契约

| 操作 | 鼠标/键盘 | iPad 触屏 | 共同规则 |
|---|---|---|---|
| 选择房间 | 单击画格 | 轻点画格 | 只改选中，不改声音/布局 |
| 播放/暂停 | 检查器/快捷按钮 | 底部控制条 | 播放受阻时就地提示“点一下播放” |
| 静音 | 一次点击 | 一次轻点 | 不再需要先展开 |
| 调音量 | 检查器滑杆/滚轮（附加） | 44px 滑杆 + ±5% | 滚轮不是唯一方式 |
| 放大 | 检查器按钮；双击为快捷 | 底部控制条“放大” | 有明确的“恢复平铺” |
| 更多操作 | 右键或“⋯” | 长按或“⋯” | 同一张动作清单 |
| 换位 | 手柄拖动；或整理模式点选 | 整理模式点选 | 取消/完成可见 |
| 弹幕设置 | 检查器/更多 | 底部面板 | 单房 vs 全局作用域明确 |
| 添加房间 | 检查器房间库 | 全宽底部面板 | 整行可选、底部托盘 |
| 关闭面板 | 显式关闭/点遮罩 | 48px 关闭/点遮罩/下滑 | 遮罩点击不穿透到视频 |
| 退出 | 更多 → 确认弹层 | 更多 → 确认弹层 | 不再用顶部 Toast 确认 |

**Esc 建议**：产品此前整体移除了 Esc 分层后退。新方案建议只恢复“关闭最上层浮层/面板”的 Esc，不恢复“Esc 退出监看”；这样既符合桌面习惯，也不会误退。若仍坚持不恢复，所有面板必须保留显式关闭按钮，且关闭后焦点回到触发按钮。

## 7. 视觉系统

### 7.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0F0F11` | 应用底（斗鱼黑暗中性黑灰） |
| `--wall` | `#09090B` | 视频墙底、视频黑边 |
| `--surface` | `#18181B` | 顶栏、检查器、控制条 |
| `--surface-2` | `#222225` | 按钮、行、浮层 |
| `--line` | `rgba(255,255,255,.08)` | 分隔线 |
| `--text` | `#F4F4F5` | 主文字 |
| `--muted` | `#B4B4BC` | 次要文字 |
| `--faint` | `#7C7C86` | 弱提示（不小于 11px） |
| `--brand` | `#FF5D23` | 主按钮 / 选中描边 |
| `--select` | `#FF7A45` | 选中、主画面、焦点环 |
| `--live` | `#3DDC97` | 直播中 |
| `--wait` | `#FBBF24` | 排队/重连/轮播 |
| `--error` | `#FF6B6B` | 异常/移除 |
| `--info` | `#60A5FA` | 取流/缓冲 |

- 品牌橙用于主按钮和选中细描边；选中不做大面积填充，品牌橙填充只给主操作。
- 状态永远“颜色 + 文字”，不单靠颜色。
- 小字（10–11px）在深底上对比度至少 4.5:1；`--faint` 只用于非关键注释。
- 视频画面保持黑色“屏幕”属性；玻璃只用于画面上的胶囊/浮层。

### 7.2 字号与间距

- PC：正文 13px，次要 11.5px，标题 15–16px，检查器数值 12px。
- iPad：正文 14–15px，列表行主名 15px，次要 12px，输入 16px。
- 不用小于 10px 的文本；状态徽章 10–11px 且配文字。
- 间距 4/8/12/16/24；面板圆角 16–20，按钮 8–10，胶囊 999。
- 画格 0–2px 圆角、墙缝 1–3px（透出斗鱼橙数据线）；不在画格内加内边距。

### 7.3 状态

| 状态 | 视觉 |
|---|---|
| 直播中 | 绿点（静态；开播提醒时才脉冲） |
| 排队/取流 | 蓝点 + “排队/连接中” |
| 未开播 | 灰点 + “未开播” |
| 重连/轮播 | 琥珀点 + 文案/倒计时 |
| 异常 | 红点 + 红字 + 重试 |
| 选中 | 2px 斗鱼橙内描边 + 名字胶囊橙描边 |
| 主画面 | 名字胶囊“主”徽标 + 检查器“放大中” |
| 静音 | 喇叭斜线图标（仅静音时出现） |
| 独奏 | 耳机图标 + “独奏”文字/徽标 |
| 开播提醒 | 6 秒绿色外发光 + Toast，不常驻动画 |

### 7.4 动效

- 悬停/按钮 140–160ms；面板 200–240ms 上滑/淡入；布局变化不做全屏 FLIP，保留现有重排即可。
- `prefers-reduced-motion` 下全部即时。
- 16 个小窗不常驻脉冲动画；只有“开播提醒/错误”等事件短暂提示。

## 9. 验收场景

1. 1440×900 PC、iPad 横屏 1180×820、竖屏 820×1180、600px 分屏均能完成：选中、播放、静音、独奏、放大/恢复、弹幕设置、添加、替换、换位、移除。
2. 全程不使用右键、双击、悬停、滚轮或拖动，也能完成全部核心操作。
3. 16 房小窗仍可轻点选中；检查器/控制条按钮不因画格缩小而低于 44px。
4. 独奏 A 时选中/放大 B，出声对象仍为 A；开启“跟随焦点”后按规则切换。
5. 弹幕设置进入时明确标注“该直播间”或“全局默认”；改一项显示“已自定义”，可恢复跟随全局。
6. 添加面板整行可选、跨搜索保留、底部托盘数量正确；部分成功保留失败勾选。
7. 选中态是斗鱼橙细描边，主画面有“主”徽标；直播/异常/排队状态不靠颜色单独表达。
8. 移除可撤销；退出是确认弹层；暂不加载进入空墙引导且不丢布局。
9. iPad 旋转/分屏/软键盘弹出后，面板、选中房间与视频节点不丢；输入框不触发自动放大；安全区域不遮按钮。
10. PiP 在无 Document PiP 的环境不出现；全屏失败回退专注视图；音量无效时显示系统音量说明。
11. `npm run build`、`npm test`、`npm run check`、`npm run smoke` 通过；真实 iPad Safari + Stay 验证播放、声音、全屏、滚动与触控。
