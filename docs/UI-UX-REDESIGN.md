## 1. 现状重建(As-Is)

### 1.1 屏幕清单与层级(Wiki §2.1 / §4.4)

```
斗鱼"我的关注"页
└─ Shadow 宿主 #douyu-monitor-userscript
   ├─ 入口徽标 [data-entry](吸附"我的关注"标题右侧)
   └─ <dialog> 监控室(全屏模态 + 页面滚动锁 + 暂停官方播放器)
      ├─ 顶栏 topbar(可收起):品牌/版本徽标/计数健康度 | 声音模式/主增益/布局预设 | 弹幕设置/全部播放/全部停止/添加房间/退出
      ├─ 画格墙 wall(自动平铺 / 1-4 列 / 焦点放大 A3 布局)
      │   └─ 画格 tile:状态胶囊(点+名) | 右上音量角标 | 底部悬浮工具条(播放/重取/独奏/弹幕/弹幕设置/画质/PiP/全屏/移除/更多) | 画格内弹幕设置浮层 | 弹幕侧栏
      ├─ 设置抽屉 drawer(右缘 56px 悬停唤起):播放/弹幕/声音提醒/预设/数据/诊断 六段长表单
      ├─ 添加面板 add-panel:关注/历史/搜索/手动(+团播)页签 + 勾选批量 + 全选 + 状态探测
      ├─ 右键菜单 ctx(12 项)/ Toast / 恢复询问 modal / 顶栏中央把手
      └─ 画中画窗口(仅桌面 Chrome/Edge,整格迁移)
```

### 1.2 现状交互模型(Wiki §4.6 / §5)

| 操作 | 桌面实现 | 触摸可用性 |
|---|---|---|
| 选择画格 | 单击 | ✅ 已有轻点唤工具条 3.5s |
| 放大/还原 | **双击** 或工具栏/右键"放大" | ⚠️ 双击慢且与浏览器手势冲突 |
| 换位 | **HTML5 drag**(标题胶囊起拖) | ❌ HTML5 DnD 在 iOS Safari 不可用 |
| 快捷操作 | **右键菜单** 12 项 | ❌ 无右键;iPad 只能靠工具条小图标 |
| 音量微调 | 角标展开滑杆 + **滚轮**(Shift 精调) | ❌ 无滚轮;角标点击区偏小 |
| 开设置抽屉 | 右缘悬停把手 / 按钮 | ⚠️ 悬停不存在,把手命中区小 |
| 收顶栏 | 顶部中央悬停区唤出把手 | ⚠️ 同上 |
| 弹幕设置 | 工具条齿轮 → 画格内浮层(小窗转 flyout) | ⚠️ 浮层在 16 分屏小格上不可用 |
| 键盘流 | 已整体移除(Wiki §9.8) | — |

### 1.3 状态覆盖盘点(Wiki §4.6 status / §5.2,这部分现状做得好,保留语义)

- 画格状态 11 态:`queued/probing/signing/connecting/playing/buffering/reconnecting/waiting/failed/blocked/stopped`,状态点三色语义(live 绿/carousel 琥珀/offline 灰,瞬态蓝,异常红)+ 计数条"n/16 格 · x 路播放 · 额度 a/c"。
- 全局态:限流冷却 30s(`cooldownUntil`)、开播提醒 Toast+beep+系统通知、恢复询问(always/never/ask)、"暂不加载"不销毁布局(pendingTiles)。
- 空态:墙空提示;加载态:spinner+阶段文案;错误态:noteEl 仅 failed/blocked 显示。

### 1.4 痛点审计(UX 检查单结论)

1. **核心操作藏在不可见手势里**:换位靠拖拽(触摸不可用)、快捷操作靠右键(触摸不可用)、抽屉/顶栏靠悬停(触摸不可用)——iPad 上"操作简单的 UI/UX"三个前提全断。
2. **控件密度与命中区矛盾**:小窗断点把工具条压到 `tools-micro(<85px)`,图标缩放后 <24px,远低于触摸 44px 底线(Wiki §4.1 tile-scale)。
3. **顶栏是"一屏全给"**:声音/增益/布局/批量/添加/退出全部常驻顶部,首次使用要先理解 6 组控件;真正高频的"添加房间"与"播放控制"反而分散两处。
4. **设置抽屉是单页长表单**(6 段),诊断/预设/数据管理混排,找回一个开关要滚动扫读。
5. **双击放大与轻点选择冲突**:触摸场景双击有 300ms 判定延迟,且误触代价(布局突变)高。
6. **PiP 是桌面专属能力**(Wiki §6.2),iPad 版按钮存在但必然失败,应降级隐藏。
7. **弹幕设置浮层在小格上空间不足**,现状靠 flyout 逃逸,层级复杂(工具条齿轮/底栏齿轮/侧栏齿轮三个入口)。

## 2. UX 决策简报(→ 平台设计契约)

```
Job: 快速搭墙 → 同屏扫视多路直播 → 对"这一路"做即时处置(声音/放大/换房/移除)→ 挂机时被开播提醒召回
User mode: 回访用户为主(工作区自动恢复),每日高频;首次 = 关注页一键批量建墙
Frequency/Risk: 高频、低风险(全部可逆;移除=可从历史/关注秒加回)
Pattern: Monitoring dashboard with priority stack + drilldown(监控墙 + 单路下钻)
Primary action(全局唯一主按钮): 添加房间(建墙期)→ 播放/暂停选中路(运营期,进 Dock 首位)
Secondary: 布局切换 / 声音三态 / 全部播放·停止 / 控制台(设置) / 退出
Core path: 进入 → 墙(恢复或引导) → 轻点选择 → Dock 即时处置 或 长按画格 → 动作表
Recovery path: 失败格就地"立即重试";限流→全局冷却横幅倒计时;误删→历史页签一键找回;暂不加载→pendingTiles 保留
Required states: 空 / 加载(分阶段文案) / 部分成功(批量添加 N 成 M 败) / 错误(429 冷却横幅) / 权限(自动播放受阻 blocked) / 成功(Toast+动作) / 长任务(重连倒计时 x/5、开播轮询指示)
Handoff constraints: Shadow DOM 内实现;单文件产物;safari15 目标;ctx 模式与分层不变;
  11 态语义与三色点不变;pendingTiles/resumeMode 语义不变;GM 存储键不变(仅 UI 层重排,数据 schema v2 不动);
  禁内联宽度(Wiki §9.5);命中区 ≥44px;PiP 按能力检测显隐;不引入网络字体
```

**设计原则(减负四条)**

1. **单手可达**:所有高频操作下沉到底部 Dock(拇指弧区),顶栏瘦身为"只读状态条"。
2. **一个手势动词(鼠标/触摸同一套 pointer 底座)**:轻点=选择,长按=对这一路做什么(动作表),双击=放大/还原,按住标题胶囊拖=换位——全部用 pointer events 实现,桌面右键只是"长按"的快捷别名(弹同一张动作表)。动作表在宽屏锚定光标渲染为菜单,触屏/窄屏自动落为底部 sheet——**一套清单,自适应呈现,不是两套模式**。
3. **渐进披露**:画格默认只露"状态点 + 主播名 + 音量角标";工具条仅选中/悬停/长按时出现;低频设置(并发、hevc、预设、诊断)进"控制台"分组 sheet,不再是一页长表单。
4. **状态即文案**:每格用一句白话状态("排队中,前面 2 路"、"重连 2/5 · 4 秒后"、"未开播 · 每分钟自动检查")+ 一个就地动作,取代只有 spinner 的猜测。

## 3. 重设计系统(To-Be)

### 3.1 布局骨架

```
┌ 状态条(顶,可收起,只读)────────────────┐
│ 斗·监控室  9/16 格 · 5 路播放 · 额度 5/8  ●运行正常  v1.5 NEW │
├──────────────────────────────────────┤
│                                        │
│            画格墙(平铺/焦点 A3)          │
│                                        │
├──────────────────────────────────────┤
│ Dock(底,常驻):◀选中路> [▶/⏸] [🔊滑杆] [独奏] [弹幕] │ ＋添加(主) │ 布局▦ │ 声音▾ │ 控制台⚙ │ 退出 │
└──────────────────────────────────────┘
```

- **Dock 左半区 = 选中画格的遥控器**:未选中时置灰并提示"轻点画面选择一路";选中后显示主播名 + 播放/暂停 + 音量滑杆(触摸加高到 44px 命中带)+ 独奏 + 弹幕开关 + 放大。等于把"右键菜单 60% 的高频项"上移成常驻,无需任何隐藏手势。
- **Dock 右半区 = 全局命令**:添加(唯一主按钮,品牌色)、布局分段(自动/1/2/3/4 收纳为一个弹出分段器)、声音模式(混音/独奏/静音三态分段)、全部播放/停止(收入溢出菜单)、控制台、退出。
- **顶栏只读化**:计数/健康/版本徽标保留;收起/展开用状态条下沿的**显式拉手按钮**(鼠标、触摸都可点),不再依赖悬停唤出;悬停仅作为桌面锦上添花的增强(`@media (hover:hover)` 内)。

### 3.2 统一手势底座(pointer events,一套动作两种输入)

| 意图 | 鼠标 | 触摸 | 实现 |
|---|---|---|---|
| 选择一路 | 单击格 | 轻点格 | `click`(pointer 层之上) |
| 这一路的操作表 | 右键 / `⋯` | **长按 350ms**(可选 `navigator.vibrate`) | `contextmenu` 与长按计时器共用 `openAction()` |
| 放大/还原 | 双击 / Dock"放大" | 双击格(自实现双击判定,免 300ms 系统延迟) / Dock"放大" | `dblclick` + tap 间隔 <350ms |
| 换位 | 按住标题胶囊拖 | 按住标题胶囊拖(同手势) | `pointerdown/move/up` + `setPointerCapture` |
| 音量 | 角标展开滑杆 / 滚轮微调 | 角标展开(44px 高命中带滑杆) / 动作表内滑杆 | 滚轮仅 `hover:hover` 设备绑定 |
| 控制台 | 右缘把手 / Dock 钮 | Dock 钮(把手同时可点) | 显式按钮为底,悬停为增强 |
| 收起顶栏 | 状态条下沿拉手 | 同左 | 显式按钮 |
| 关闭浮层 | 点击外部 | 点击外部 / sheet 下滑 | pointer 判定 |
| PiP | 能力检测:有 `documentPictureInPicture` 才显示 | 同左——iPad Safari 无此 API,自动不出现 | 运行时检测,非模式开关 |

长按与拖拽的仲裁:pointerdown 起 350ms 计时;期间位移 >10px → 取消长按;标题胶囊上的按住移动直接进换位拖拽;350ms 无位移 → 弹动作表(触摸带震动反馈)。桌面右键跳过计时,直接弹同一张表(锚定光标)。

### 3.3 动作表(单一路由,取代 右键菜单+更多菜单+工具条 三套入口)

分组呈现,破坏性动作隔离在底部:

> 画格悬浮控制栏(工具条)只保留高频七键:播放/暂停 · 重新取流 · 弹幕开关 · **弹幕设置** · 放大/还原 · 全屏 · 移除。
> **独奏不进工具条**(属"对这一路做什么"的处置类,归动作表与 Dock 遥控器),避免小窗断点下按钮过多被收纳。

```
[主播名 · 房号 · ●直播中]
播放控制   ▶ 暂停/继续   ⟳ 重新取流   ⏹ 停止
声音       🔇 静音(开)   🎧 独奏     —————  每路音量 [滑杆]
画面       ⤢ 放大/还原    ▣ 全屏      (PiP 仅能力检测通过时列出)
弹幕       💬 开/关      ≡ 弹幕设置(独立 sheet,不再画格内浮层)
房号       ✎ 换房(替换模式,保留位置与偏好)
──────────
🗑 移除该房间(红色,单击即删 + Toast"已移除 · 撤销"5s —— 用撤销替代确认)
```

### 3.4 添加面板(触摸化)

保持四页签 + 跨页勾选 + 全选语义(Wiki §4.6),改三点:
- 行高 56px、复选框 28px、整行可点(点行=勾选,点"添加"=单加);
- 状态徽章(直播中/轮播/未开播/检查中/已添加)不变,探测进度显示"已校对 24/40";
- 批量结果用"部分成功"文案:`已添加 6 个,2 个跳过(已存在)` + 保留失败勾选(现状语义)。

### 3.5 控制台(设置分组 sheet)

抽屉长表单 → 右侧 sheet(桌面优先形态;窄屏/粗指针自动落为底部 sheet)四段,默认收起摘要:
`播放`(并发额度·H.265·恢复方式) / `弹幕`(全局默认·应用所有房间) / `声音与提醒`(自动静音·跟随焦点·开播提醒三开关) / `工作区`(预设存取·清空历史·诊断折叠)。

### 3.6 视觉方向:systematic + industrial control-room

- 延续现有资产:近黑蓝底、冷蓝主色、0.5px 墙缝数据线、毛玻璃胶囊、三色状态点、mono 版本徽标——**监控室的既有身份,不推倒**。
- **主题体系(uicraft 配色工作流重构,两层 token)**:
  - **设计层用 OKLCH 定标**:感知均匀,L 明度步进=视觉步进;表面分三级(底 L≈15% / 层1 / 层2,深色主题层次靠"越浮越亮"而非阴影);近白近黑降 chroma 防俗艳;中性色全部带主题 hue 微染(冷调/暖调 cast),告别死灰。
  - **落地层输出 hex**:iOS15/Safari15 对 `oklch()` 支持不稳(15.4+ 才完整),Stay 版产物直接写 OKLCH 派生的静态 hex,零兼容风险。
  - **组件只引用语义 token**(`--bg/--panel/--panel2/--line/--ink/--dim/--faint/--acc/--acc-soft/--hover/--ring/--live/--loop/--off/--busy/--bad/--on-video`),换主题=只重映射语义层;半透明收敛为实色 token,**唯一保留 alpha 的语境是视频上的浮层**(胶囊/工具条/状态条——透出画面是功能本身)。
- **主题/配色由用户重选**(原型元栏五套即时切换,localStorage 记忆):

| 候选 | 定位 | 外壳(OKLCH 思路) | 强调色 | 语义色策略 | 对应生产 |
|---|---|---|---|---|---|
| Studio 深空监看 | 默认,夜间长挂 | 冷调 cast≈250,底 L15% | 冷蓝 #3ea1f2 | 恒定标准 | `studio` 延续 |
| Titanium 钛银日班 | 白天/办公亮色 | 暖纸 cast≈75,底 L93% | 钢蓝 #2b62a8 | 全套加深保 AA | `titanium` 重定义 |
| Stealth 夜隐墨青 | 极低亮度护眼 | 近黑 L10%(非纯黑)+青 cast | 墨青 #37b3a0 | 降饱和防眩 | `stealth` 重调 |
| Ember 炭火广播台 | 差异化暖身份 | 暖炭 L15% cast≈60 | 铜橙 #d98e3c | 恒定;状态点+文字双编码防红橙混淆 | 新增(需扩 `THEMES`) |
| Contrast 高对比 | 无障碍/强光环境 | 纯黑+白字,粗描边 | 高亮黄 #ffd60a | AAA 增强 | 新增(建议 `a11y`) |

  规则:状态语义(绿直播/琥珀轮播/灰未开播/蓝取流中/红异常)**跨主题含义恒定且永不单靠颜色**(点+一句式文字);视频画格在任何主题保持深色"屏幕"属性;强调色遵守 60-30-10——accent 只花在 CTA/选中/焦点,稀缺才有牵引力。
- **建议的生产扩展**:主题枚举 `studio/titanium/stealth/ember/contrast`;`resumeMode` 旁增"跟随时间自动切换"(白天 titanium/夜间 stealth,仅默认值,手动优先)。
- 字体:生产约束不可联网加载字体(Wiki §9),用受控栈:UI 用系统中性无衬线;元数据/数字/状态用等宽栈(`ui-monospace, 'SF Mono', 'JetBrains Mono', Consolas`),大写距 mono 小标签作"仪表盘铭牌"母题。
- 几何:胶囊 999px 只用于状态/工具;sheet 16px;画格 4px 直角无缝——禁止全站同圆角。
- 动效预算(运营面,3 个签名时刻):① 放大/还原的 FLIP 布局变形;② 动作表/sheet 200ms 弹性上滑(触摸)与光标淡入(桌面);③ 状态点色彩过渡 + 重连倒计时数字 tick。`prefers-reduced-motion` 全部退化为即时切换。禁滚动特效。
- 触摸密度:命中区 ≥44px,图标 ≥20px;`touch-action: manipulation` 禁双击缩放;safe-area 内边距。

### 3.7 状态覆盖(必须可见于原型,含非 happy path)

| 态 | 呈现 |
|---|---|
| 空墙 | 引导卡:一键添加全部在播关注(主)/ 打开添加面板 |
| 恢复询问 | 居中 modal(桌面优先;窄屏自动落底部 sheet):加载上次(6)/暂不加载,记住选择开关 |
| 加载链 | 每格一句式阶段文案 + 额度横幅"额度 8/8,2 路排队中" |
| 未开播 | 灰点 + "未开播 · 每分钟自动检查" + 动作"开播自动播放 ✓" |
| 重连 | 琥珀→红渐变点 + "重连 2/5 · 4 秒后自动重试" + [立即重试] |
| 失败 | 红点 + 脱敏原因 + [重试][换房][移除] |
| 自动播放受阻 | "浏览器阻止了自动播放,点一下画面" 大点按区 |
| 限流冷却 | 顶栏下方全局横幅:"接口冷却中 · 23 秒" 倒计时,期间取流按钮禁用态 |
| 开播提醒 | Toast(动作:立即播放/忽略)+ 格体描边脉冲 10s |
| 部分成功 | 添加结果行内文案 + 失败保留勾选 |

## 4. iPad 触摸适配(单设计内的自适应,非独立模式;Wiki 约束对照)

1. **产物**:stay 版同源码双轨构建,safari15/ios15 target——重设计只用 iOS15 已支持能力:pointer events、`aspect-ratio`、`backdrop-filter`(-webkit)、dialog 元素在 Stay 沙箱可用(现状已在用);不依赖 `:has`。
2. **无 Document PiP**:运行时 `'documentPictureInPicture' in window` 能力检测,无则动作表不列 PiP 项——iPad Safari 自然不显示,无需任何开关。
3. **无悬停**:所有 affordance 都有显式可点控件(Dock 钮、状态条拉手、音量角标);悬停样式(`.tile:hover .tools`、右缘把手渐显)只写在 `@media (hover:hover)` 内,触摸设备走"选中即显形"。
4. **尺寸自适应**:命中区 ≥44px、添加行 56px 是**全局默认**(桌面同样受益,不是触摸专属);sheet 呈现位置随 `pointer:coarse`/视口宽度自动选右侧或底部。
5. **横竖屏**:竖屏焦点布局主窗在上、小窗横向带在下(对应 A3 引擎 E 族天然占优,`anchor` 参数已有);横屏沿用现方案——由 CSS 容器查询/媒体查询自动完成。
6. **滚动锁与下拉刷新**:面板内 `overscroll-behavior: contain`,拖拽元素 `touch-action: none`,防误触 Safari 下拉/双击缩放。
