# 放大模式：综合均衡

正式播放器采用调研前的五种结构：右侧列排、底部行排、L 型、左右分列、U 型。布局按画墙实际可用尺寸选择，不设置按房间数量切换的固定断点。

## 硬约束与取舍

- 1～16 房全部同屏，主窗位于整体矩形左上或水平居中、顶部对齐。
- 所有副窗等宽等高；画格与源视频比例一致，无内部黑边、裁切、拉伸或空槽。
- 整体拼成完整矩形并最大化等比适配，外围仅一条轴上对称留白。
- 默认主副窗面积目标为 6 倍，优先范围 3～16 倍；同源比例下，宽高目标约各 2.45 倍，上限各 4 倍。整格约束决定实际倍数，不能连续放大。
- 评分为 `覆盖率 − 0.12 × abs(log2(主副面积比 / 目标面积比))`。相对目标的面积误差每增加一倍，需要约 12 个百分点覆盖率抵消；每种结构内部和跨结构使用相同评分。
- 没有适中放大解且源比例相同时，回退完整等大网格，例如 14 房；2 房同向同源比例在当前几何约束下只能等大。
- 相同房间身份、主窗、源比例和面积目标下，旧排列重新计算坐标后仍有效、且评分收益不超过 0.02 时保留旧排列。主窗或比例变化不使用旧场景的稳定偏好。

指定主窗的副窗比例不一致时，先尝试其他房间作为主窗，不能直接判定整个场景不可行。例如 4 个横屏加 1 个竖屏，可自动把竖屏作为主窗，让其余横屏副窗保持等大、原比例且无内部黑边；切换时提示用户，保留选中房间和原媒体节点。当前主窗已经可行时，不因覆盖率偏好自动换主播。

只有检查全部主窗仍不可行时，才清理放大坐标、恢复普通平铺并提示原因；例如 2 个横屏加 2 个竖屏，移出任意一个作为主窗后，副窗仍混合比例。主窗可以与副窗比例不同，使用其真实比例重新求解；若不能等大回退，则展示仍真实可行、最接近目标的方案。

## 模块与数据流

- `src/core/focus-layout-geometry.js`：统一单元枚举、浮点坐标、覆盖率和严格审计。
- `src/core/focus-layout-policy.js`：五种结构选优、综合评分、等大回退和切换阈值。
- `src/core/focus-layout.js`：正式播放器适配，先解析可行主窗，再保留对应房间身份及副窗索引，返回绝对坐标。
- `src/app/layout.js`：读取视频元数据与容器尺寸，定位原媒体或画中画占位节点；恢复平铺时清除全部固定坐标。
- `preview/recursive-layout-engine.js`、`recursive-layout-variants.js`：兼容导出上述正式模块，避免预览与产品规则分叉。

```text
ResizeObserver / 窗口变化 / 视频元数据 / 主窗切换
→ requestAnimationFrame 合并布局请求
→ 读取画墙实际宽高、主房间身份与各视频源比例
→ 优先指定主窗；副窗比例冲突时尝试其他主窗，仅全无解时退出放大
→ 枚举严格合法的统一单元矩形
→ 结构内部按面积范围和综合评分选优
→ 跨结构比较，必要时等大回退
→ 重新生成旧候选，收益不足阈值时保留有效旧排列
→ 审计数量、比例、等大、重叠、矩形完整及单轴留白
→ 把绝对坐标写入原画格或画中画占位
```

仅更新定位和尺寸，不修改流地址、音量、弹幕设置或播放器实例；已有 `moveBefore` 与播放状态恢复逻辑继续用于必要的节点迁移。没有新增接口、持久化字段或数据库变更。

## 场景示例与验证

2246×994、全部 16:9，综合均衡默认目标 6 倍：

| 房间数 | 主副面积比 | 覆盖率 | 结果 |
| --- | --- | --- | --- |
| 5 | 16× | 98.35% | 右侧列排 |
| 8 | 9× | 78.68% | L 型 |
| 10 | 16× | 78.68% | L 型 |
| 12 | 9× | 98.35% | U 型，可保留等效的原 L 型 |
| 14 | 1× | 36.31% | 全等大网格 |
| 15 | 16× | 94.41% | U 型 |

留白受整格与面积范围限制，例如 11 房在当前范围内仍有较多外围留白。目标是综合取舍，不承诺所有数量都满屏。

```powershell
yarn build
yarn test
yarn run check
node --check dist/douyu-monitor.stay.user.js
node scripts/build-layout-preview.mjs
```
