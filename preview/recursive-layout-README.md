# 等大小窗排列预览

交付文件 `layout-options-preview.html` 内嵌完整脚本、Tailwind 样式和模拟信号生成器，可单独离线打开。默认展示 8 房，跟随画墙实际可用尺寸，以“综合均衡”自动选优，继续使用调研前的五种放大结构供比较；没有适中放大解时增加 F 全等大网格回退。支持 1–16 房、固定/自定义尺寸、切换主窗与源比例。

所有候选都严格满足：

- 每套方案内的所有副窗等宽等高，左右及底部共用同一尺寸。
- 每个画面保持源比例，完整显示，不裁切、不拉伸、无格内黑边。
- 所有窗口无缝拼满一个矩形，内部没有空槽。
- 整体最大化等比适配画墙，外围只在上下或左右一组对称留白。
- 主窗位于整体矩形左上，或水平居中、顶部对齐。

只比较排列方式，不提供尺寸分档或跳过一致性审计的模式。

## 场景自动更新

默认“综合均衡”适当提高主窗比例，同时评价覆盖率和大小差距。主窗面积目标 `t` 从 4 调到 6，优先范围为 `[max(2, t/2), 8t/3]`，默认 3～16 倍面积。6 倍面积在同源比例下对应宽高各约 2.45 倍；上限 16 倍对应各 4 倍。完整矩形的整格条件会让实际可选倍数离散变化，目标不意味着可以连续拉伸主窗。

综合评分为 `视频覆盖率 − 0.12 × |log2(主副面积比 / t)|`，先筛选范围再评分。在结构内部和跨结构之间共用此规则；相对目标的面积误差增加一倍，需要约 12 个百分点的覆盖率收益才能抵消。单房间不计算面积差惩罚。允许主窗适当放大以换取明显的覆盖收益，但覆盖收益不足时保留较小主窗。参数是此次微调采用的设计取舍，不是调研项目的标准。

“大小均匀”保留此前较严格的规则：先控制主副窗面积差，再优化留白。其范围仍为 `[max(2, t/2), 2.25t]`，目标 4 时为 2～9 倍面积。范围随面积滑块调整，预览同时展示面积比和真实宽高倍数，避免混淆。显式链接中的 `weight` 会原样保留；进入综合均衡的新链接未设置目标时默认使用 6，其余模式默认使用 4。切换取舍保留当前滑块，方便在相同目标下对比。

大小筛选同时发生在每个结构内部和跨结构选优时，避免只把五个已经被覆盖率放得过大的结果拿来比较。每种结构优先保留范围内候选，再选覆盖率最高的解；该结构无范围内候选时，保留最接近面积目标的解供手动查看，并标记过大差距。自动模式优先使用范围内结构，不被额外几个百分点覆盖率诱导去选择 49 或 169 倍主窗。

综合均衡及大小均匀模式中，若所有放大结构均超过各自上限，且所有视频源比例一致，自动回退 F 全等大网格；枚举房间总数的整行整列排列，选择最适应画墙的矩形。14 房在相同源比例下最小放大面积差仍为 36 倍，默认因此回退网格。主窗标记及切换功能保留，所有窗口尺寸一致。该回退已由用户明确允许。主副窗源比例不同时不能使用全等大网格，仍选择真实可行的最接近目标的放大方案并展示实际倍数。

“覆盖最全”（原“留白最少”）保留覆盖率优先规则，用于对照；该模式可能出现很大的主副窗差距。三种规则都不使用固定房间数或显示器型号作为布局切换断点。

综合均衡在大小筛选后按综合评分排序，再按覆盖率、面积目标误差、相同房间及主窗的原排列、巡视距离消除并列；其他模式仍先按覆盖率排序。并列只容忍 `1e-9` 浮点误差。综合均衡对同一房间、主窗、比例及目标的旧候选另外设置 0.02 分切换阈值：旧候选仍在范围内、收益不超过阈值时保留原排列；明显收益或约束变化时立即切换。每次都重新生成坐标，不复用旧分辨率的几何。

判断依据是播放器画墙实际可用宽高，而非显示器标称分辨率或固定房间数断点。窗口缩放、跨屏后可用尺寸变化、全屏、房间数、主窗、源比例或面积偏好变化都会重新选优。`ResizeObserver` 监听容器，40 ms 合并变化，过期计算取消提交。

并非所有数量都放大：2650×1000、5 房中，16 倍主窗虽能多约 9.3 个百分点覆盖率，评分仍保留 4 倍主窗；2246×994 下相同数量因覆盖收益约 34.8 个百分点，选择 16 倍。11 房默认仍保留 4 倍主窗，外围留白较多：其下一档放大面积为 25 倍，超出此次保守上限，不通过破坏矩形或副窗一致性填空。

覆盖率受源比例、全局等大、完整矩形和面积差范围共同约束。控制差距可能增加外围留白，尤其某些数量只能组成较细长的矩形；不通过空槽、裁切或拉伸掩盖这一取舍。少量房间也可以在很宽的画墙上选到左右居中结构，无需人为指定几房开始围绕。

手动选择 A–E 会固定排列结构，并应用当前大小/留白取舍；仍按新尺寸重新求坐标。对比卡显示“自动推荐”，可随时从方案下拉框恢复自动。F 只在当前输入需要网格回退时出现，点击 F 恢复自动并查看回退大图。选择固定或自定义分辨率时，以该目标画墙选优；要跟随当前显示环境，请选择“跟随当前窗口”。1–16 总览分别计算每个数量的自动方案，并标出真实面积与宽高差距。

## 算法

几何与选优代码已迁入 `src/core/focus-layout-geometry.js`、`src/core/focus-layout-policy.js`，由预览和正式放大模式共用；原预览模块保留兼容导出。输入画墙宽高、房间 ID 与源比例、主窗和排列类型，输出实际坐标、统一副窗尺寸、覆盖率及审计结果。预览只显示本地模拟信号，不调用直播接口或数据库。

设副窗比例为 `r`，统一单元宽高为 `r×1`，主窗占 `u×v` 单元，侧栏列数为 `a`，底栏行数为 `b`，副窗数为 `n`：

```text
确认所有副窗源比例相同，否则明确返回不可行原因
主窗比例 = r × u / v
n = a × v + b × (u + a)
仅侧栏：枚举 n 的因数，得到整数 v，u 按主窗比例计算
仅底栏：枚举 n 的因数，得到整数 u，v 按主窗比例计算
侧栏与底栏都有：u、v、a、b 必须为正整数，并严格满足数量方程
按排列类型筛选：右列、底行、L、左右对称、U
左右对称要求侧栏总列数为偶数，两侧各放 a / 2 列
全局可放大主窗时，不允许某种结构退化成主副窗等大来冒充放大模式
综合均衡（默认）：先筛选面积差范围，再比较覆盖率与大小差距的综合评分
大小均匀：保留较严格范围，在范围内优化外围留白
覆盖最全：直接比较覆盖率，面积目标仅用于并列决策
所有放大结构都超过大小上限且源比例相同：自动求解整行整列的等大网格
用同一个浮点单元宽高生成所有副窗，不逐格取整
从最终几何审计源比例、全局等大、数量、重叠、空洞、主窗锚点和单轴外围留白
```

综合均衡默认面积偏好为副窗的 6 倍；旧大小均匀规则默认偏好 4 倍。可行时保留至少 2 倍的主窗效果。两路相同源比例在完整矩形中只能等大，会明确提示放大限制。某些数量没有 L/U 型解，不能仅缩小主窗解决。

自动入口 `calculateLayoutVariant(options, "auto")` / `calculateAutomaticLayout(options)` 默认采用 `priority: "compromise"`；`priority: "balanced"` 保留旧大小均匀规则，`priority: "coverage"` 保留覆盖最全规则。所有结构及网格回退使用同一套统一单元算法与不可绕过的严格审计。原底层 `calculateRecursiveLayout` 的有限覆盖损失策略及调研候选预览保留用于对照。
