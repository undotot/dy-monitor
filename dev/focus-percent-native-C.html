新算法与指标说明

N 减少主窗黑边：覆盖率距当前条件下最佳候选不超过 2 个百分点，优先减少主窗内部黑边，再比较实际视频占用。

C 紧凑完整画面：先选择最高窗口覆盖率，再减少主窗内部黑边。两种方案都统一小窗短边，保留完整小画面。

加入主窗比例匹配的连续断点，避免固定比例模板遗漏更少黑边的布局。主视频实际面积至少保留单窗最大视频的 52%，并至少为最大小视频的 2.5 倍。

默认间隔 0px。少量空位是优化目标，无法对任意比例承诺固定上限；N 的 2 个百分点是相对最佳可行覆盖率，不是整墙空位上限。

宽百分比相对墙宽，高百分比相对墙高。相同宽高百分数不能保证原比例，改变墙面比例时重新计算；所有小窗短边一致。

独立预览待选择 N 或 C 后接入。伪代码见 docs/focus-percent-native.md；无后端、接口或数据库变更。
